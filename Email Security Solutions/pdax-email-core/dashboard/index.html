          Gateway enforcement
          
              
          Detection & monitoring always run regardless of mode — only the blocking action changes. Keep on Monitor only during your testing phase.
          
            
          
            Monitor only
          
          
          
          
            
          
              
              
              
            
          
          
          
          
          
          
          
            
          
              Monitor only (shadow) — every email is scored, logged, and shown here. Nothing is blocked or held. Recommended for live testing.
          
              Quarantine — suspicious and malicious mail is held in the spool; legitimate mail still delivers normally.
          
              Reject — malicious mail is hard-rejected at the gateway. Enable only after validating detection quality in shadow mode.
            
          
          
          
        
          

        
        
          
          
          
            
          
              
          Protection policy
          
              
          Category toggles — enable or disable entire detection families. Changes take effect on the next email processed.
